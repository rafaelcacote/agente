Um site fictício para testar o widget embeddable

Esta é uma página HTML estática, sem Laravel — simula o site de um cliente que integrou o agente com uma única tag <script>.

O widget aparece no canto da tela. Abra o chat, envie mensagens e recarregue a página para verificar se a conversa foi retomada via localStorage.

CORS: para este HTML funcionar em outro domínio, cadastre a origem em CORS_ALLOWED_ORIGINS (.env) e em tenants.settings.allowed_origins. No mesmo domínio da API (como aqui), funciona sem configuração extra.
